Configurar Servidor DHCP no Windows Server

No Windows Server, a configuração do DHCP é simples, principalmente se você usar o Gerenciador do Servidor.

Pela Interface Gráfica (Mais Fácil)

  1. Instale a função DHCP.
  2. Abra o Gerenciador do Servidor (Server Manager).
  3. Clique em Gerenciar e Adicionar Funções e Recursos.
  4. Escolha Instalação Baseada em Função ou Recurso.
  5. Selecione o servidor.
  6. Marque Servidor DHCP (DHCP Server).
  7. Clique em Avançar até instalar.

Após a instalação, clique em Concluir Configuração DHCP (Complete DHCP Configuration) e siga o assistente.

Depois, abra o console DHCP, e no Gerenciador do Servidor vá em Ferramentas e DHCP e crie um escopo. No console DHCP:

  1. Expanda o nome do servidor.
  2. Clique com o botão direito em IPv4.
  3. Selecione Novo Escopo.
  4. Configure o escopo.

Exemplo:


Nome do escopo

Rede Local

Faixa de IPs

Início: 192.168.1.2
Fim:    192.168.1.254

Máscara

255.255.255.0

Ao configurar o tempo de concessão, o padrão de 8 dias costuma ser adequado.

Configure as opções:


Gateway (Router)

192.168.1.1

DNS

8.8.8.8
1.1.1.1

Em um ambiente com Active Directory, normalmente o DNS informado é o próprio controlador de domínio.

Ao final do assistente, escolha Ativar este Escopo.O DHCP começará a fornecer endereços imediatamente.

Usando PowerShell

Instale a função:


Install-WindowsFeature DHCP -IncludeManagementTools

Crie um escopo:


Add-DhcpServerv4Scope `
-Name "Rede Local" `
-StartRange 192.168.1.2 `
-EndRange 192.168.1.254 `
-SubnetMask 255.255.255.0

Configure o gateway:


Set-DhcpServerv4OptionValue `
-Router 192.168.1.1

Configure o DNS:


Set-DhcpServerv4OptionValue `
-DnsServer 8.8.8.8,1.1.1.1

Pra verificar se está funcionando, no console DHCP, você pode acompanhar:

  • Address Leases (Concessões de Endereço): Mostra quais clientes receberam IP.
  • Address Pool (Pool de Endereços): Exibe a faixa configurada.
  • Reservations (Reservas): Permite associar um IP fixo a um dispositivo pelo endereço MAC.

Em um cliente Windows, execute:


ipconfig /release
ipconfig /renew
ipconfig /all

Se tudo estiver correto, o computador receberá um endereço dentro da faixa configurada (por exemplo, 192.168.1.2 a 192.168.1.254) e o comando ipconfig /all mostrará o servidor DHCP que concedeu o endereço.

Importante: O servidor DHCP deve ter um IP estático e, em uma mesma rede (mesmo segmento), normalmente deve existir apenas um servidor DHCP ativo, para evitar conflitos na distribuição de endereços IP.
