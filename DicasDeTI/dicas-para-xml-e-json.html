Uso de XML e JSON

XML

XML é uma linguagem para organizar e transportar dados usando tags. Ele é parecido com o HTML, mas este é basicamente para estruturar uma página para ser apresentada e tem tags específicas. O XML estrutura dados para serem armazenados ou trocados, e podemos criar nossas próprias tags.

As tags são demarcadores que, em sua maioria, têm abertura e fechamento (abertura com <tag> e fechamento com </tag>) e o conteúdo fica entre as duas (incluindo outras tags).

Exemplo:


<?xml version="1.0" encoding="UTF-8"?>
<!--
* Isso é um comentário em XML, semelhante ao de HTML
* A tag acima define a versão e a codificação do documento.
-->
<pessoa>
    <nome>João</nome>
    <idade>25</idade>
    <cidade>São Paulo</cidade>
    <casado status="false"/> <!-- Tag "vazia" sem fechamento, com barra no final -->
</pessoa>

A tag pessoa é o elemento, e as tags nome, idade, cidade e casado são os dados dentro dele. As tags indicam o que cada informação significa.

PS: Como visto acima, podemos também ter tags sem fechamento (no caso acima, a casado), nesse caso colocamos uma barra no final dela obrigatoriamente (diferente do HTML que é opcional).

Em resumo: XML estrutura dados de forma hierárquica e legível tanto por humanos quanto por sistemas.

XML é usado principalmente para armazenar, organizar e trocar dados entre sistemas. Por exemplo:

  • Comunicação entre sistemas (APIs e integrações).
  • Arquivos de configuração de programas.
  • Documentos estruturados.
  • Troca de informações entre empresas e sistemas diferentes.
  • Feeds e arquivos, como RSS e alguns formatos de documentos.

Imagine um XML representando um pedido de uma loja:


<?xml version="1.0" encoding="UTF-8"?>
<pedido id="12345">
    <cliente>
        <nome>João Silva</nome>
        <email>joao@email.com</email>
        <endereco>
            <rua>Rua das Flores</rua>
            <numero>100</numero>
            <cidade>São Paulo</cidade>
            <estado>SP</estado>
            <cep>01000-000</cep>
        </endereco>
    </cliente>
    <produtos>
        <produto codigo="A001">
            <nome>Notebook</nome>
            <quantidade>1</quantidade>
            <preco>3500.00</preco>
        </produto>
        <produto codigo="B002">
            <nome>Mouse</nome>
            <quantidade>2</quantidade>
            <preco>100.00</preco>
        </produto>
    </produtos>
    <pagamento>
        <metodo>Cartão de crédito</metodo>
        <parcelas>10</parcelas>
    </pagamento>
    <total>3700.00</total>
    <entrega fazer="true"/>
</pedido>

Hoje, JSON é mais comum em APIs web, mas XML ainda é muito usado em sistemas corporativos, financeiros e governamentais.

JSON

JSON é um formato para organizar e trocar dados, parecido com XML, mas geralmente mais simples e compacto. Por exemplo:


{
    "nome": "João",
    "idade": 25,
    "cidade": "São Paulo",
    "casado": false
}

No caso, nome, idade, cidade e casado são as chaves, e João, 25, São Paulo e false são os valores. O símbolo de chaves ({}) é o conjunto de dados (objeto), e os colchetes ([]) é a lista de valores. Valores numéricos e lógicos (como 25 e false) se colocam sem aspas, apenas strings ficam entre aspas.

Em resumo: JSON organiza informações em chave → valor e é muito usado em APIs e aplicações web.

JSON nasceu inspirado na sintaxe de objetos do Javascript, mas hoje é usado praticamente por qualquer linguagem para trocar dados entre sistemas.

O mesmo pedido ficaria assim em JSON:


{
    "pedido": {
        "id": 12345,
        "cliente": {
            "nome": "João Silva",
            "email": "joao@email.com",
            "endereco": {
                "rua": "Rua das Flores",
                "numero": 100,
                "cidade": "São Paulo",
                "estado": "SP",
                "cep": "01000-000"
            }
        },
        "produtos": [
            {
                "codigo": "A001",
                "nome": "Notebook",
                "quantidade": 1,
                "preco": 3500.00
            },
            {
                "codigo": "B002",
                "nome": "Mouse",
                "quantidade": 2,
                "preco": 100.00
            }
        ],
        "pagamento": {
            "metodo": "Cartão de crédito",
            "parcelas": 10
        },
        "total": 3700.00,
        "entrega": true
    }
}
