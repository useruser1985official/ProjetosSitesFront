Configurando DHCP no Ubuntu Server

A forma mais simples é usar o servidor DHCP do pacote ISC DHCP Server. Embora existam alternativas mais novas, ele continua sendo fácil de configurar e muito usado.

Pra começar, instale o servidor DHCP, atualize os pacotes e instale o serviço:


sudo apt update

sudo apt install isc-dhcp-server -y

Descubra o nome da interface de rede, listando as interfaces:


ip a

Você verá algo como:


enp0s3
ens33
eth0

Anote a interface conectada à rede onde o DHCP irá distribuir endereços.

Defina a interface, pra isso edite o arquivo:


sudo nano /etc/default/isc-dhcp-server

Procure por:


INTERFACESv4=""

Altere para:


INTERFACESv4="enp0s3"

# Substitua enp0s3 pelo nome da sua interface.

Configure a faixa de IPs, pra isso edite:


sudo nano /etc/dhcp/dhcpd.conf

No final do arquivo, adicione:


default-lease-time 600;
max-lease-time 7200;
authoritative;

subnet 192.168.1.0 netmask 255.255.255.0 {
    range 192.168.1.2 192.168.1.254;
    option routers 192.168.1.1;
    option subnet-mask 255.255.255.0;
    option domain-name-servers 8.8.8.8, 1.1.1.1;
}

Nesse exemplo:

  • Rede: 192.168.1.0/24
  • Gateway: 192.168.1.1
  • Faixa entregue pelo DHCP: 192.168.1.2 até 192.168.1.254
  • DNS: Google e Cloudflare

Configure um IP fixo no servidor, O servidor DHCP deve ter um endereço IP estático.

No Ubuntu Server moderno, edite:


sudo nano /etc/netplan/00-installer-config.yaml

Exemplo:


network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: no
      addresses:
        - 192.168.1.10/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1

Aplique:


sudo netplan apply

Reinicie o serviço:


sudo systemctl restart isc-dhcp-server

Verifique se iniciou corretamente:


sudo systemctl status isc-dhcp-server

Verifique os logs, e se houver algum erro:


sudo journalctl -u isc-dhcp-server

# ou

sudo tail -f /var/log/syslog

Para teste, conecte um computador à mesma rede e configure-o para obter IP automaticamente. Em seguida, verifique se ele recebeu um endereço dentro da faixa 192.168.1.2 – 192.168.1.254.

Exemplo completo:

Servidor DHCP:

  • IP: 192.168.1.10
  • Gateway: 192.168.1.1

Clientes receberão:

  • IP: 192.168.1.2–254
  • Máscara: 255.255.255.0
  • Gateway: 192.168.1.1
  • DNS: 8.8.8.8 e 1.1.1.1

Essa configuração é suficiente para a maioria dos laboratórios, máquinas virtuais e pequenas redes locais.
