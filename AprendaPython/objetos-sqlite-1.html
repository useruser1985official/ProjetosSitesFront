    Objetos SQLite em Python - Parte 1

    Aprenda SQL do Zero

    Como sabemos, o computador tem a memória principal (RAM) para armazenar dados e programas durante o uso, mas ela só mantém os dados enquanto o computador está ligado, e ele não os armazena de forma definitiva, para guardar os dados e programas de forma definitiva, devemos guardar na memória secundária (como o HD ou o SSD), para que ele permaneça de forma definitiva até quando queremos.

    Para guardar dados como, por exemplo, nome e idade de um usuário, podemos guardar num arquivo como um de texto, mas pra organizar e manipular os mesmos, é melhor usarmos os bancos de dados. De certa forma, o banco de dados funciona de forma parecida, guardando os dados como a memória secundária (definitiva), só que eles organizam de forma mais organizada.

    Um banco de dados tem várias coisas dentro deles, basicamente o principal são tabelas (como se fosse pastas), e dentro das tabelas tem registros. As tabelas podem ser feitas para coisas diferentes, como clientes, fornecedores e produtos, para os organizar, e eles podem ter ligações entre si.

    Esse tipo de banco de dados são chamados de bancos relacionais, alguns dos bancos mais conhecidos são o PostgreSQL, MySQL, MariaDB, Oracle e Microsoft SQL Server, todos baseados numa mesma linguagem, o SQL, só que esses bancos de dados precisaríamos instalar servidores robustos, já que eles são usados para grandes quantidade de dados, como servidores web, por exemplo. Para facilitar o uso com o Python podemos usar o SQLite, que embute o banco SQL em um arquivo.

    Para criar um banco de dados SQLite, podemos salvar um arquivo com a extensão .sqlite ou .db3 (como meubanco.db3), e dentro de um programa de manipular SQLite, podemos criar uma tabela assim:

    
create table amigos (
    id integer primary key,
    nome text not null,
    nascimento date not null
);

    E inserir dados assim:

    
insert into amigos (nome, nascimento) values
('João Santos', '1995-04-12'),
('Beatriz Lima', '2001-11-23'),
('Rafael Costa', '1988-07-05');

    E para consultar, podemos fazer de forma simples:

    
select * from amigos;

    E de uma forma mais detalhada, usando operadores relacionais:

    
select nome, nascimento from amigos where nascimento >= '2000-01-01';

    Numa ferramenta de GUI, podemos criar de forma gráfica os bancos, além de inserir os registros diretamente, de forma mais fácil, no entanto, deveremos saber os comandos SQL para trabalhar com Python.

    SQLite, Consultas e SQL Injection

    Um banco de dados, para ser acessado, precisa ter uma linguagem de exploração, que é o SQL, pois as linguagens não o acessam diretamente. Para acessar o SQLite em Python, usaremos o módulo sqlite3, uma conexão e um objeto do tipo Cursor para acessar os dados.

    Já criamos o banco de dados na aula anterior, agora iremos manipular o mesmo. Pegue o banco e adicione esses dados:

    
insert into amigos (nome, nascimento) values
('Breno Santos', '1995-04-12'),
('Beatriz Lima', '2001-11-23'),
('Gabriel Costa', '1988-07-05'),
('Amanda Brito', '2001-03-30'),
('João Sérgio', '1998-12-22'),
('Cláudio Mendonça', '1985-05-10'),
('Sérgio Silva', '2003-01-24'),
('Silvia Martins', '2008-10-02'),
('Enzo Gabriel', '2025-01-20'),
('Valentina Brito', '2022-03-12'),
('Gustavo Guanabara', '1978-03-17');

    Basicamente, podemos conectar ao banco assim:

    
import sqlite3

banco = sqlite3.connect("meubanco.db3")
cur = banco.cursor()

cur.execute("select * from amigos") # Aqui vai qualquer comando de SQL

print(cur)

cur.close()
banco.close()

    Só que isso retornará o endereço do objeto, para ver os dados, devemos colocar assim:

    
import sqlite3

banco = sqlite3.connect("meubanco.db3")
cur = banco.cursor()

cur.execute("select * from amigos") # Aqui vai qualquer comando de SQL

lista = cur.fetchall()

print(lista)

cur.close()
banco.close()

    Só que ainda não tratamos corretamente os dados do SQLite dessa forma.

    Como sabemos, os dados ficam na memória secundária (como o HD) e para vermos os dados deveremos passar ele pra memória principal (como a RAM). O método fetchall()pega todos os registros do banco e joga na memória e exibe, mas isso pode dar problemas caso tenhamos muitos cadastros no banco (como 1 milhão). Para puxar os dados de um em um, usamos o método fetchone(), que ocupará apenas um dado na memória.

    Vamos alterar assim:

    
import sqlite3

banco = sqlite3.connect("meubanco.db3")
cur = banco.cursor()

cur.execute("select * from amigos") # Aqui vai qualquer comando de SQL

for amigo in cur:
    print(amigo)

cur.close()
banco.close()

    No caso acima, ele mostra todos os dados, mas cada dado ocupará um espaço na memória por vez (ou seja, só o primeiro ocupa, depois é substituído pelo segundo, terceiro, até chegar no fim).

    Podemos formatar também o que está dentro do for, já que o que estará na variável amigo será uma tupla, assim:

    
for amigo in cur:
    print(f"{amigo[1]} nasceu em {amigo[2]}")

    Para pegar os nomes literais das colunas no SQL, altere o início assim:

    
import sqlite3

banco = sqlite3.connect("meubanco.db3")
banco.row_factory = sqlite3.Row
cur = banco.cursor()

cur.execute("select * from amigos") # Aqui vai qualquer comando de SQL

for amigo in cur:
    print(f"{amigo['nome']} nasceu em {amigo['nascimento']}") # Dá pra usar tanto os números quanto os nomes

cur.close()
banco.close()

    Podemos usar boas práticas para que ele feche o cursor automaticamente, sem precisar fechar toda hora, dessa forma:

    
import sqlite3

with sqlite3.connect("meubanco.db3") as banco:
    banco.row_factory = sqlite3.Row
    cur = banco.cursor()

    cur.execute("select * from amigos") # Aqui vai qualquer comando de SQL

    for amigo in cur:
        print(f"{amigo['nome']} nasceu em {amigo['nascimento']}")

print("ACABOU!") # Tá fora do with

    Só que isso pode dar erros caso algum cadastro esteja cadastrado errado ou o banco não exista. Vamos colocar esses cadastros no SQLite com o ano no formato errado propositalmente:

    
insert into amigos (nome, nascimento) values
('Joãozinho', '2000'), -- Erros propositais de ano
('Sérgio Marconi', '');

    Aí ele pode até passar, mas se colocarmos o nome de uma coluna que não existe dentro do for, vai dar erro:

    
import sqlite3

with sqlite3.connect("meubanco.db3") as banco:
    banco.row_factory = sqlite3.Row
    cur = banco.cursor()

    cur.execute("select * from amigos") # Aqui vai qualquer comando de SQL

    for amigo in cur:
        print(f"{amigo['nome']} nasceu em {amigo['nacimento']}")

print("ACABOU!") # Tá fora do with

    Aí, nós podemos tratar ele colocando tudo dentro de um try except, assim:

    
import sqlite3

try:
    with sqlite3.connect("meubanco.db3") as banco:
        banco.row_factory = sqlite3.Row
        cur = banco.cursor()

        cur.execute("select * from amigos") # Aqui vai qualquer comando de SQL

        for amigo in cur:
            print(f"{amigo['nome']} nasceu em {amigo['nacimento']}") # Erro proposital
except sqlite3.Error as erro:
    print(f"Falha no banco: {erro}")
except Exception as erro:
    print(f"Algo deu errado {erro}")

print("ACABOU!") # Tá fora do with

    No caso acima, ele cairá no erro genérico, mas se ele, por exemplo, não encontrar o banco, ele dará o erro do banco SQLite.

    Podemos filtrar com uma busca também, alterando assim:

    
import sqlite3

busca = str(input("Quem você está procurando? ")).strip()

try:
    with sqlite3.connect("meubanco.db3") as banco:
        banco.row_factory = sqlite3.Row
        cur = banco.cursor()

        cur.execute(f"select * from amigos where nome like '%{busca}%'")

        for amigo in cur:
            print(f"{amigo['nome']} nasceu em {amigo['nascimento']}")
except sqlite3.Error as erro:
    print(f"Falha no banco: {erro}")
except Exception as erro:
    print(f"Algo deu errado {erro}")

print("ACABOU!") # Tá fora do with

    No caso acima, podemos procurar um trecho de nome (como silv), ele procurará todos os nomes que contenham essa string.

    Só que colocar os dados diretamente na SQL, pode ser perigoso por causa do SQL Injection. Essa forma aqui não deve ser usada:

    
cur.execute(f"select * from amigos where nome like '%{busca}%'")

    Para resolver essa vulnerabilidade, usaremos consultas preparadas, na qual colocamos a interrogação na query SQL e passamos os parâmetro via uma tupla. Dessa forma:

    
cur.execute("select * from amigos where nome like ?", (f"%{busca}%",)) # Não esqueça da vírgula no final

    Só de colocar a consulta assim, já evita a injeção de SQL.

    PS: Ao não passar nada, ele retornará todos os dados normalmente, mas não dará mais erro ao passar caracteres que podem ser interpretados como comandos, como o '.

    Podemos também contar a quantidade de registro, assim:

    
total = 0

for total, amigo in enumerate(cur, start = 1):
    print(f"{amigo['nome']} nasceu em {amigo['nascimento']}")

print(f"Ao todo encontrei {total} amigos com \"{busca}\"")

    Código completo abaixo:

    
import sqlite3

busca = str(input("Quem você está procurando? ")).strip()

try:
    with sqlite3.connect("meubanco.db3") as banco:
        banco.row_factory = sqlite3.Row
        cur = banco.cursor()

        cur.execute("select * from amigos where nome like ?", (f"%{busca}%",)) # Não esqueça da vírgula no final

        total = 0

        for total, amigo in enumerate(cur, start = 1):
            print(f"{amigo['nome']} nasceu em {amigo['nascimento']}.")

        print(f"Ao todo encontrei {total} amigos com \"{busca}\".")
except sqlite3.Error as erro:
    print(f"Falha no banco: {erro}")
except Exception as erro:
    print(f"Algo deu errado {erro}")
