    Objetos SQLite em Python - Parte 2

    O Que é CRUD? Aprenda a Criar um Sistema com Python

    A sigla CRUD é um acrônimo para create, read, update e delete, que é criar, ler, atualizar e apagar, ou seja, as funcionalidades básicas que tem numa tabela em um banco de dados.

    Vamos criar por código um banco SQLite, sem precisar de ferramentas para o manipular diretamente. O banco cadastro.db3 terá uma tabela de nome pessoas, com as colunas cod, nome e altura.

    O sistema em Python que faremos terá essas opções:

    1. Cadastrar pessoa.
    2. Listar pessoas.
    3. Atualizar pessoa.
    4. Excluir pessoa.
    5. Busca por nome.
    6. Sair.
